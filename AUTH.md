# Auth & Profiles

## Regra

Primeiro descobrir se autenticação já existe. Não substituir solução
funcional.

## Perfis

Cada pessoa pode possuir: - display name; - username; - avatar; -
capa; - bio.

## Permissões

-   criar posts;
-   editar/excluir próprios posts;
-   comentar;
-   curtir;
-   salvar;
-   visualizar conteúdo privado autorizado.

## Escopo

O app foi pensado para um espaço privado. Não criar sistema público de
seguidores no MVP.

## Sessão

Preservar estratégia atual de sessão/autenticação.

## Segurança

Autorização deve ser validada no backend/database quando disponível, não
somente escondendo botões.
