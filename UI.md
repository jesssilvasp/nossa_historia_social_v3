# UI --- Social Romantic Design System

## Conceito

Estrutura inspirada em redes sociais de timeline, especialmente o padrão
de navegação de três áreas no desktop, mas com identidade própria.

Não copiar logos, ícones proprietários, textos ou identidade visual do
Twitter/X.

## Paleta

-   Primary: #F43F75
-   Pink Medium: #FB718F
-   Pink Light: #FDA4AF
-   Pink Pastel: #FECBD5
-   Background: #FFF1F4
-   Surface: #FFF9FA
-   Text Primary: #3F2631
-   Text Secondary: #80616D
-   Border: rgba(244,63,117,.14)

## Desktop

### Esquerda

Sidebar fixa: - logo Nossa História de Amor - Início - Notificações -
Nosso Mural - Álbuns - Músicas - Momentos - Perfil - Configurações -
botão Criar Momento

### Centro

Feed: - cabeçalho - composer - filtros opcionais - posts

### Direita

Painel afetivo: - Nossa História - tempo juntas - próxima data
especial - Tocando agora - memória antiga/recordação

## Mobile

-   header compacto;
-   feed em largura total;
-   bottom navigation;
-   botão flutuante para criar post;
-   painéis laterais viram páginas/cards secundários.

## Composer

Texto: "Compartilhe um momento... 💕" Ações: - Foto - Vídeo - Música -
Momento especial Botão: Publicar

## Post

-   avatar;
-   nome;
-   @username;
-   data/horário;
-   texto;
-   mídia;
-   música opcional;
-   badge de momento especial;
-   curtir;

-   salvar;
-   menu.

-   sombras mínimas;
-   bordas suaves;
-   doodles discretos;
